### [RU] Destructy - это мощный чит имеющий функционал, полностью доступный с клиента.
При установке рекомендую изучить [Wiki](https://github.com/Chair6798/Destructy/wiki/Installation-guide) в котором по шагам описана установка.
При возникновении проблем или желания добавить функцию перейдите в раздел [Issues](https://github.com/Chair6798/Destructy/issues) и добавьте новый с тэгом bug если вы нашли ошибку, и feature-request если вы хотите предложить новую функцию.

### [EN] Destructy is a powerful cheat with all features fully accessible from the client.
When installing, I recommend checking the [Wiki](https://github.com/Chair6798/Destructy/wiki/Installation-guide), which provides a step-by-step installation guide.
If you encounter any issues or want to suggest a new feature, go to the [Issues](https://github.com/Chair6798/Destructy/issues) section and create a new issue with the `bug` label if you've found a bug, or the `feature-request` label if you'd like to suggest a new feature.
